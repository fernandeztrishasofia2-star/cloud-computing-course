# Cloud Computing Concepts Reflection

Cloud computing plays a significant role in my everyday life because many of the digital services I use rely on cloud technology. Three cloud-based applications that I frequently use are Google Drive, Facebook Messenger, and Canva.

Google Drive is classified as **Software as a Service (SaaS)** because it enables users to store, manage, and share files online without installing specialized software on their devices. It follows the **Public Cloud** deployment model since it is accessible to anyone with an internet connection and a Google account.

Facebook Messenger is another example of **Software as a Service (SaaS)**. It offers cloud-based messaging, voice calls, and video calls through an online platform. Messenger is deployed on the **Public Cloud** because it is available to millions of users around the world over the internet.

Canva is also considered **Software as a Service (SaaS)** because it provides online tools for creating presentations, posters, graphics, and other visual content directly from a web browser. It uses the **Public Cloud** deployment model since users can access its services from anywhere with an internet connection.

Version control is an essential part of cloud computing projects because it keeps a complete history of changes made to files, code, and system configurations. This allows developers to recover previous versions whenever errors occur. Git makes it easy to monitor and manage changes, while GitHub provides a collaborative platform where teams can work together, review updates, and organize projects efficiently. Features such as branches, pull requests, and commit history help reduce conflicts and improve collaboration. By using GitHub, developers can manage cloud resources, documentation, and project files more effectively. Overall, cloud computing and version control contribute to more efficient teamwork, better project management, and more reliable software development.
